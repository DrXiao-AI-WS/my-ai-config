# my-ai-config

Aggregates public "agents & skills" repositories, plus this repo's own
hand-authored ones, for AI coding tools (Claude Code, Codex, GitHub
Copilot, OpenCode, Google Antigravity) into a single local source of
truth, and exposes them to each tool via symlinks — no duplicated files
per tool.

## How it works

`fetch-then-config-agents-skills.sh`:

1. Clones/updates a built-in list of public repos into `./source`.
2. Scans that tree, plus this repo's own `./local` tree, for agents
   (`*.md` files directly inside a directory named `agents`) and skills
   (any directory directly containing a `SKILL.md`), and symlinks each
   one into `./agents` and `./skills`.
3. Ensures `~/.agents` is a symlink to this repo directory (detected
   dynamically, regardless of what this checkout is named or where it
   lives), then symlinks `~/.agents/agents` and `~/.agents/skills` into
   each tool's expected config location:
   - Claude: `~/.claude/agents`, `~/.claude/skills`
   - Codex: `~/.codex/agents`
   - Copilot: `~/.copilot/agents`
   - OpenCode: `~/.config/opencode/agents`
   - Antigravity: `~/.gemini/config/agents`, `~/.gemini/config/skills`

Detection is content-based rather than name-based, so it works no matter
how deeply agents/skills are nested inside a cloned repository.

## Usage

```bash
./fetch-then-config-agents-skills.sh [source_dir]
```

`source_dir` defaults to `~/.agents/source`.

## Repository layout

- `AGENTS/` — hand-maintained, always-loaded agent instructions tracked in
  this repo (imported by each tool's top-level config, e.g. `CLAUDE.md`).
- `local/` — hand-authored agents (`local/agents/*.md`) and skills
  (`local/skills/<name>/SKILL.md`) tracked in this repo, aggregated by the
  script exactly like ones cloned from external repos. Use this for
  agents/skills that only matter contextually, rather than the always-on
  rules under `AGENTS/`.
- `fetch-then-config-agents-skills.sh` — the sync/link script.
- `source/`, `agents/`, `skills/` — generated by the script (cloned repos
  and derived symlinks); intentionally excluded via `.gitignore` since
  they're reproducible output, not source.
